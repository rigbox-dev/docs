Available **local**. Reference source: CLI `0.13.0-rc.5` (`824aefd6ad16`).

Use this command from your local terminal; it isn't available inside a workspace. `--dry-run` lists what would be deleted and changes nothing. Without a terminal, `--confirm EMAIL` confirms with your account email instead of the interactive prompt.

## Examples

<Warning>
This command permanently deletes your account and everything it owns. Run it with `--dry-run` first and copy out anything you need.
</Warning>

List what would be deleted, without deleting anything.

```bash
rig account delete --dry-run
```

Run from your local terminal. Replace uppercase placeholders with your own values. This invocation permanently deletes the account.

```bash
rig account delete --confirm EMAIL
```

Inspect the supported arguments before running this command. Help is offline and does not modify resources.

```bash
rig account delete --help
```

## Local syntax

```text
Usage: rigbox account delete [OPTIONS]
```
