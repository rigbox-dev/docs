Available **local**. Reference source: CLI `0.13.0-rc.5` (`824aefd6ad16`).

Run this command on your local machine. Inside a workspace, `rig ssh` refuses with a one-line message; run it from your laptop. Account SSH keys are never managed from inside a workspace.

## Examples

Inspect the supported arguments before running this command. Help is offline and does not modify resources.

```bash
rig ssh --help
```

## Local syntax

```text
Usage: rigbox ssh [OPTIONS] <COMMAND>
```
