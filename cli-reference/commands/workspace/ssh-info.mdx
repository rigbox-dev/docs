Available **local and workspace**. Reference source: CLI `0.13.0-rc.5` (`824aefd6ad16`).

Use this command from your local terminal. Prints the workspace's SSH host and user, the short `ssh` alias when rig manages your SSH config, and the full `ssh USER@HOST` command. It also sets up SSH access from this machine, as `rig ssh add` does. Inside a workspace it describes that workspace and takes no `--workspace`.

## Examples

Run from your local terminal. Replace uppercase placeholders with your own values. This invocation performs the operation described above.

```bash
rig workspace ssh-info --workspace WORKSPACE_ID
```

Print the details as JSON for scripts; `ssh_target` is always present and `ssh_alias` appears once SSH access is set up.

```bash
rig workspace ssh-info --workspace WORKSPACE_ID --output json
```

Inspect the supported arguments before running this command. Help is offline and does not modify resources.

```bash
rig workspace ssh-info --help
```
