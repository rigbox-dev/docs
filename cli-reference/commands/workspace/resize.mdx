Available **local and workspace**. Reference source: CLI `0.13.0-rc.2` (`09bd4024dd72`).

Use this command from your local terminal. Workspace-mode syntax, when available, is listed separately below.

## Examples

<Warning>
This command changes an existing resource or its configuration and may affect a running application. Confirm the target and review the complete help before running the example.
</Warning>

Run from your local terminal. Replace uppercase placeholders with your own values. This invocation performs the operation described above.

```bash
rig workspace resize --workspace WORKSPACE_ID
```

Inspect the supported arguments before running this command. Help is offline and does not modify resources.

```bash
rig workspace resize --help
```

## Local syntax

```text
Usage: rigbox workspace resize [OPTIONS] --workspace <WORKSPACE>
```

### Arguments and flags

| Argument | Description | Details |
| --- | --- | --- |
| `-w, --workspace` | Workspace name or id | Required; Value: WORKSPACE |
| `--ram` | New RAM allotment in MB | Value: RAM |
| `--vcpu` | New vCPU count (minimum: 1) | Value: VCPU |
| `--disk` | New disk size in MB | Value: DISK |
| `--output` | Output format [default: human, or `rig config set output …`] | Global; Value: OUTPUT; Choices: human, json, yaml, text, table |
| `--query` | Filter output with a JMESPath expression | Global; Value: JMESPATH |
| `--cli-input-json` | Read inputs from a JSON file or &#x27;-&#x27; (stdin) | Global; Value: FILE |
| `--cli-input-yaml` | Read inputs from a YAML file or &#x27;-&#x27; (stdin) | Global; Value: FILE; Conflicts: cli_input_json |
| `--generate-cli-skeleton` | Print a fillable input template, then exit | Global; Default: false |
| `--no-pager` | Do not pipe help output through a pager | Global; Default: false |
| `-v, --verbose` | Verbose diagnostics on stderr: per-phase deploy tracing, job-poll status, and transport commands. Useful for debugging a slow or stuck `rig deploy` | Global; Default: false |
| `-h, --help` | Print help |  |
