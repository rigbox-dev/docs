Available **local**. Reference source: CLI `0.13.0-rc.5` (`824aefd6ad16`).

Use this command from your local terminal. Registers a public key on your account and sets up `ssh <workspace>` on this machine: a `Host` entry per workspace in `~/.config/rigbox/ssh_config`, which `~/.ssh/config` includes. Without `--file` it uses `~/.ssh/id_ed25519.pub`, then `~/.ssh/id_rsa.pub`, and creates an ed25519 key when you have neither. Without `--name` the key is named `laptop-` followed by your host name. A key that is already on your account is reported, not added again.

## Examples

Register your default key, creating one if needed, and set up `ssh <workspace>` for your workspaces.

```bash
rig ssh add
```

Register a specific public key under a name you choose.

```bash
rig ssh add --name work-laptop --file ~/.ssh/work_ed25519.pub
```

Inspect the supported arguments before running this command. Help is offline and does not modify resources.

```bash
rig ssh add --help
```

## Local syntax

```text
Usage: rigbox ssh add [OPTIONS]
```

| `-f, --file` | Path to public key file (default: ~/.ssh/id_ed25519.pub, created if you have no key) | Value: FILE |
| `--output` | Output format [default: human, or `rig config set output …`] | Global; Value: OUTPUT; Choices: human, json, yaml, text, table |
| `--query` | Filter output with a JMESPath expression | Global; Value: JMESPATH |
