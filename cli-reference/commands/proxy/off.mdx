title: "rig proxy off"

description: "Print unset statements to deactivate the proxy"
---

Available **workspace**. Reference source: CLI `0.13.0-rc.5` (`824aefd6ad16`).

Use this command inside a workspace. Prints `unset` statements for the variables `rig proxy on` sets, but only those that still point at the managed proxy or hold its placeholder key; your own provider keys and base URLs are left alone. Apply the output with eval, as for `rig proxy on`.

## Examples

Run inside a workspace. Replace uppercase placeholders with your own values. This invocation performs the operation described above.

```bash
rig proxy off
```

Inspect the supported arguments before running this command. Help is offline and does not modify resources.

```bash
rig proxy off --help
```

## Workspace syntax

```text
Usage: rigbox proxy off [OPTIONS] [PROVIDER]
```
