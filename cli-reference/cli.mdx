The `rig` and `rigbox` commands run the same CLI. This reference is generated from **v0.13.0-rc.2** and is part of the v0.13 documentation preview.

Start with [installation](/guides/install-cli) and [authentication](/cli-reference/authentication). For a working application, follow the [quickstart](/quickstart).

## Find a command

Choose a command family in the sidebar, then drill down to a command. Each page includes its execution mode, example invocations, arguments, flags, and complete help. Common starting points:

[Configuration and output](/cli-reference/configuration) explains scripting options. [Local versus workspace CLI](/cli-reference/execution-modes) explains which command surface to use.

## Source and coverage

The command tree comes from the CLI's Clap definitions at revision `09bd402`, including both local and workspace modes. Hidden internal commands and Clap's automatically generated `help` routing aliases are excluded; every documented command supports `--help`.

Syntax and flags are generated independently of maintained examples. Examples containing uppercase placeholders require your values. Commands that create, change, or delete resources perform those operations when run; `--help` is always offline.
