## Documentation scope

This draft covers [paid plans and add-ons](/concepts/pricing-and-billing), [account resource accounting](/concepts/limits), and [managed wallet behavior](/ai/managed-wallet). It removes monthly free-bucket promises from the staged wallet schema. New paid plans include no AI grant; existing funds and eligible transition access are described separately.

## API source status

The staged wallet and limits components come from an offline primary-server gateway export at **`652120cb2273c0383158cdd15136542ab59b74f1`**, using the exact repository and CI pin **Rust 1.93.1**. The complete auth-service schema comes from its pure library exporter at the same source revision and toolchain. Neither export starts a service, connects to a database, or fetches the live API.

Only the selected wallet and limits components are synchronized into the existing gateway spec, preserving unrelated gateway definitions. `auth-api.json` is the complete actual auth-service export, replacing its historical duplicated gateway specification. Billing pages reference handler-exported paths and request schemas, not prose-inferred contracts. The combined gateway export omits subscription-status and the two existing checkout/portal paths; the auth export contains all eight documented billing operations.

Several billing responses are generated as generic JSON objects because the source handlers return `serde_json::Value`. This is a schema typing limit, not permission to assume fields or grant access. Exact schemas may change before final release. The committed [provenance record](/verification/paid-pricing.json) lists both hashes, source revision, toolchain, and remaining release gates.
