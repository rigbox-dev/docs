<Info>
These endpoints manage HTTPS tunnels under `rigbox.link`. Use the signed CLI
0.13.1 or later to run the local connector. Read the
[exposure and shared-browser-site risks](/guides/local-tunnels#shared-browser-site)
before sharing an app.
</Info>

Lists the current account's tunnel records, including their hostname, target, access policy, and connection state. A record does not establish that a connector is running or that its website is reachable.

Stopped and expired records remain listed until the owner [deletes their history](/api-reference/tunnels/delete-record).

See [local tunnels](/guides/local-tunnels) to start a connector and share its website.
