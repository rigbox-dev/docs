Alongside the limits and usage, the response carries the paid entitlement: `compute_allowed`, `entitlement_status`, `pricing_transition_until`, `billing_paid_through` and `billing_revision`. The account's sustained CPU budget is `limits.sustained_cpu_millis` against `usage.running_cpu_millis`; 1,000 millicores are one core of sustained CPU time. See [resource limits](/concepts/limits).
