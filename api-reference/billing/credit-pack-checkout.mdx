<Note>
**Console only.** This operation needs a signed-in console session; an API key or CLI login gets `404`. Use Billing in the console. See [pricing and billing](/concepts/pricing-and-billing#integration-and-retry-behavior).
</Note>

An active verified paid subscription is required to purchase optional managed AI credits. A $13 pack buys 1,000 credits representing approximately $10 of upstream usage, with 30% markup included in the pack price. The purchase is one-time; neither checkout creation nor return parameters grant wallet funds. Verify the durable operation before treating the grant as applied.

Account billing requires an authenticated account identity with appropriate billing permissions. Workspace bridge identity is not an account billing credential. See [managed wallet](/ai/managed-wallet) for the financial contract.
