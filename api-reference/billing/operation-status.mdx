<Note>
Readable with an API key, so scripts and `rig limits` / `rig whoami` can show billing state. See [pricing and billing](/concepts/pricing-and-billing#integration-and-retry-behavior).
</Note>

Read an operation owned by the authenticated account. Operations may be creating, pending_payment, pending_period_end, applied, expired, or failed. Verify the server-confirmed operation and relevant subscription or wallet projection; a browser marker is not a financial receipt. The generated response schema is generic JSON.

Account billing requires an authenticated account identity with appropriate billing permissions. Workspace bridge identity is not an account billing credential. See [managed wallet](/ai/managed-wallet) for the financial contract.
